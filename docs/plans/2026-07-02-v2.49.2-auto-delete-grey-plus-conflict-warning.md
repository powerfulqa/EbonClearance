# v2.49.2 Implementation Plan - Auto-delete grey on loot + conflicting-addon warning

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two opt-in Delete Settings toggles: (1) auto-delete grey items the moment they land in bags (bag-space priority over vendor copper); (2) warn once per login when a third-party auto-delete addon is detected running alongside EC.

**Architecture:** Two independent scans - grey-delete piggybacks the existing BAG_UPDATE debounce alongside auto-mark-Resilience / auto-mark-affix-dupes; conflict warning fires once at PLAYER_LOGIN via a neutral-framed detection helper. Both are additive schema, defaults preserve existing behaviour on v2.49.1 upgrade.

**Tech Stack:** Lua 5.1, WoW 3.3.5a APIs (`IsAddOnLoaded`, `GetContainerItemID`, `GetItemInfo`, `MerchantFrame:IsShown`, `PickupContainerItem` + `DeleteCursorItem`, `StaticPopup1EditBox`). Existing EC infrastructure: `EnsureDB`, `EC_compCache`, `NS.PrintNice`, `NS.IsInSet`, delete-popup mutex from `EbonClearance_Delete.lua`.

**Spec:** [`docs/specs/2026-07-02-v2.49.2-auto-delete-grey-plus-conflict-warning-design.md`](../specs/2026-07-02-v2.49.2-auto-delete-grey-plus-conflict-warning-design.md)

Structural template (adapt to match the sibling auto-mark scans' actual shape):

```lua
-- v2.49.2: auto-delete grey items on loot. Runs from the BAG_UPDATE
-- debounce alongside runAutoMarkResilience / runAutoMarkAffixDupes.
-- Opt-in via DB.autoDeleteGreyOnLoot, gated on DB.enableDeletion
-- (master switch), MerchantFrame closed (vendor round-trip yields
-- copper), item quality 0, positive sellPrice (avoids trashing quest
-- keys / 0-value curiosities), not a quest item, and not on any Keep
-- List variant. Delete via PickupContainerItem + DeleteCursorItem +
-- the shared popup mutex.
local function runAutoDeleteGrey()
    if not DB.enableDeletion or not DB.autoDeleteGreyOnLoot then
        return
    end
    if MerchantFrame and MerchantFrame:IsShown() then
        return
    end
    for bag = 0, 4 do
        local slots = GetContainerNumSlots(bag) or 0
        for slot = 1, slots do
            local itemID = GetContainerItemID(bag, slot)
            if itemID then
                local _, _, quality, _, _, itemType, _, _, _, _, sellPrice = GetItemInfo(itemID)
                if quality == 0
                    and sellPrice and sellPrice > 0
                    and itemType ~= "Quest"
                    and not IsEquippedItem(itemID)
                    and not NS.IsInSet(DB.blacklist, itemID)
                    and not (ADB and NS.IsInSet(ADB.whitelist, itemID))
                    and not (DB.blacklistAuto and DB.blacklistAuto[itemID])
                    and not NS.IsInSet(DB.deleteList, itemID)
                then
                    -- Use the shared delete-popup path. NS.DeleteBagSlot
                    -- handles the mutex + StaticPopup1EditBox + confirm.
                    if NS.DeleteBagSlot then
                        NS.DeleteBagSlot(bag, slot, itemID)
                        return  -- one delete per BAG_UPDATE burst
                    end
                end
            end
        end
    end
end
```
